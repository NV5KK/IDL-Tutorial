# Getting Started with IDL

NV5 Geospatial 株式会社が提供する、IDL 製品トレーニング用の入門教材です。
はじめて IDL に触れる方を対象に、Jupyter Notebook 形式で基本操作から画像処理・可視化・信号処理・マッピング・プログラミングまでを、演習を通して段階的に学べる構成になっています。

開発環境には **IDL for Visual Studio Code** を使用します。

> [!IMPORTANT]
> **本教材の実行には IDL のライセンスが必要です。**
> ノートブックの閲覧は GitHub 上でも可能ですが、コードを実行するには有効な IDL ライセンスがインストールされた環境をご用意ください。

## はじめに

まずは [00_overview.ipynb](00_overview.ipynb) を開いてください。全体の目次がまとまっています。
その後、番号順に進めることをおすすめします。

## 実行環境

### 必要なもの

- IDL（有効なライセンスが必要）
- Visual Studio Code
- IDL for VSCode 拡張機能

### カーネルについて

各ノートブックの kernelspec は `idl`（IDL Kernel for Jupyter）を指定しています。
IDL for VSCode 経由で IDL ノートブックとして開く場合、拡張機能が対応するカーネルへ自動的に紐付けられます。
環境構築の詳細は [02_before_starting.ipynb](02_before_starting.ipynb)（「2. 演習に入る前に」）を参照してください。
